# Bravo Warehouse

نظام إدارة مخازن مصنع براڤو برو.

## المميزات
- إدارة الأصناف.
- إدارة المخازن.
- الوارد والمنصرف.
- التحويلات المخزنية.
- المرتجعات.
- الجرد والتسويات.
- التقارير بالكميات فقط.
- النسخ الاحتياطي.
- العمل دون إنترنت.

## Technology
- Kotlin
- Jetpack Compose
- Room Database
- MVVM Architecture
